Project Methodology

Complete workflow followed in building the Food Delivery Time Prediction system from data collection to web deployment.

1. Data Collection

Collected dataset containing delivery-related features such as distance, weather, traffic level, preparation time, and courier experience.

2. Data Preprocessing

Handled missing values, cleaned data, converted categorical variables using encoding techniques, and prepared dataset for training.

3. Exploratory Data Analysis

Analyzed data distribution, relationships between features, and identified key factors affecting delivery time.

4. Feature Engineering

Selected important features and transformed variables to improve model performance and prediction accuracy.

5. Model Building

Implemented regression models including Linear Regression, Decision Tree, Random Forest, and Support Vector Regression.

6. Model Evaluation

Evaluated models using R² score, MAE, MSE, and RMSE to select the best performing model.

7. Model Saving

Saved the trained model using joblib for later use in deployment and prediction.

8. Web Development

Designed a user-friendly web interface using HTML, CSS, and Bootstrap template for input and output display.

9. Model Deployment

Integrated machine learning model with Flask backend to provide real-time delivery time predictions through the website.
