# 🍔 Food Delivery Time Prediction System

## 📌 Overview
This project is a **machine learning-based web application** that predicts food delivery time based on various real-world factors such as distance, traffic conditions, and order details.

It integrates **Machine Learning, Flask backend, and a responsive frontend UI** to provide accurate delivery time predictions.

---

## 🚀 Features
- Predict food delivery time instantly  
- User-friendly web interface  
- Machine learning model integration  
- Handles real-world features like traffic conditions  
- Flask-based backend system  
- SQL database support
